## How I work

- **Security first** — end-to-end encryption, memory-hard password hashing, tamper-evident logs, and least-privilege roles as defaults, not afterthoughts.
- **Verify, don't trust** — hash chains and public verification pages beat "trust me".
- **Ship the whole thing** — protocol design, FastAPI/Node backends, React frontends, Docker deploys.
